There is nothing quite like walking on stage to give a talk with vibe coding in the title immediately after a talk detailing all the structural and verification crises of vibe coding. =)

The three-talk lineup inadvertently formed an amusing story arc for where software engineering is at right now:

1. Andrés-Leonardo Martínez-Ortiz kicked things off with "Critical Engineering: The Myth of Ireneo Funes — Redefining the SDLC, Operations (SRE), and Engineering Education", unpacking what happens when autonomous agents make generating code almost free, while verification and integration costs skyrocket.
2. Then I stepped up for "Flutter, Antigravity SDK, and GenUI, a vibe coding exploration" — which made for a hilarious transition, and set up some wonderful questions from the crowd.
3. Maksim Lin rounded out the night with "Making Antigravity skills for unusual file formats", showing how to build custom Antigravity Agent Skills and Golang tooling so agents can actually make sense of specialised XML Music data formats that aren't plentiful in the training data.

We are living in a real time of discovery as we figure out what these tools do well, and what they need help with.
